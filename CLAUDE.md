## Что это за проект

**Capital Dashboard** — личный дашборд капитала (личный контур + контур компании).
Веб-приложение, которое сводит в одну картину: крипту (по адресам в блокчейне),
наличные/авто/прочие активы, расходы (из Google Sheets), дивиденды, и отдельно
баланс компании (USDT-кошельки + рекламные агентства) с расчётом «доступно к выводу».

Вся индикация — в долларах США. Рублёвые суммы пересчитываются по курсу ЦБ РФ.

**Источник истины по продукту — `PRD.md`.** Там по фичам расписано, что видит
пользователь, как считается каждая цифра, откуда берутся данные, и журнал уже
выполненных доработок (раздел 10). При расхождениях приоритет у раздела 9 PRD.

## Стек и инфраструктура

- **Next.js 14** (App Router, TypeScript) + **React 18**.
- **Postgres + Prisma** (схема — `prisma/schema.prisma`, контракт по mock-данным).
- **Docker / docker-compose** + **Caddy** (авто-HTTPS) — 4 контейнера: app, db,
  worker (cron-синхронизации на `node-cron`), caddy.
- Аутентификация: один пользователь, пароль (bcrypt) → JWT в httpOnly-cookie (`jose`).
- Деплой: VPS, GitHub Actions по SSH (`git pull && ./deploy.sh`).

## Карта кода (где что лежит)

- `src/app/(dash)/` — страницы разделов (Обзор, Инвестиции, Расходы, Дивиденды,
  Активы, Компания).
- `src/app/api/` — роуты: `auth/`, `health/`, ручной ввод (`assets`, `agencies`,
  `dividends`, `reserves`, `wallets`, `company/wallets`), и синки `sync/*`
  (`crypto`, `expenses`, `telegram`, `coinlink`, `tonnums`, `dividends`).
- `src/components/views/` — экраны; `src/components/*Modal.tsx` — модалки ввода.
- `src/lib/` — доменная логика: `data.ts` (сборка данных дашборда), `types.ts`,
  `fx.ts` (ЦБ-курс), `sheets.ts` (Google Sheets), `crypto/providers.ts`
  (балансы BTC/EVM/TRON/TON), `coinlink/db.ts` (внешняя БД), `tonnums/price.ts`,
  `telegram.ts`, и `sync/*` (логика каждого синка).
- `src/worker/index.ts` — cron-воркер: ждёт готовности app (`/api/health`),
  дёргает синк-эндпоинты с `CRON_SECRET` по расписанию.
- `prisma/` — `schema.prisma`, `seed.ts`, `import-company-wallets.ts`
  (идемпотентный импорт адресов компании, гоняется на каждом деплое), миграции.
- Документация: `PRD.md` (продукт), `README.md` (обзор), `DEPLOY.md` (развёртывание
  с нуля), `TELEGRAM.md` (настройка бота агентств).

## Конвенции и стиль работы (как ждёт заказчик)

- **Язык — русский.** Вся коммуникация, коммиты, документация, комментарии — по-русски.
- **Коммиты** — короткое содержательное описание по-русски, по сути изменения
  (примеры из истории: «Активы: ввод в рублях с автопересчётом в $ по курсу ЦБ»).
  PR-мерджи в прод оформляются с номером PR.
- **Веди журнал в PRD.** Каждую заметную доработку фиксируй отдельной датированной
  записью в `PRD.md` → раздел 10 («Журнал реализации»): запрос → реализация →
  устойчивость → конфигурация. Это сложившаяся традиция проекта, заказчик на неё
  опирается.
- **Принцип устойчивости (PRD §7).** Любой внешний источник может быть недоступен.
  Никогда не обнуляй данные при сбое: показывай последнее известное значение +
  бейдж свежести «обновлено N назад». Синк должен падать ДО записи, а не затирать
  нулём.
- **Без двойного счёта** (PRD §9). Деньги между контурами движутся согласованно:
  крипта/авто оцениваются отдельно, дивиденды/расходы влияют только на кэш;
  операция вывода = лог + дивиденд, баланс не трогает (отток ловится синком).
- **Конфигурация через ENV, без хардкода.** Источники, периоды, ключи, расписания —
  всё переопределяется переменными окружения (см. `.env.example`).
- **Секреты не коммитятся.** Реальные значения живут только в `.env` и `secrets/`
  на сервере и в GitHub Secrets. В репозитории — только `.env.example` с плейсхолдерами.
- **Сеть в песочнице ограничена.** Часть внешних API (например, `api.getgems.io`)
  режется egress-фильтром среды; живые данные подтягиваются на VPS с открытой сетью.
  Это нормальная причина, по которой синк «не видит» источник из песочницы.

## Внешние интеграции (по одной строке)

- **Google Sheets** — расходы (лист «Отчет») + доходы/дивиденды (ДДС-лист). ₽→$ по ЦБ.
- **CoinMarketCap** — котировки монет.
- **Блокчейн-эксплореры** — балансы BTC / Ethereum / BSC / Tron / TON. Компания —
  только USDT (TRC20/BEP20/ERC20). Tron: только свободный (нестейканный) TRX.
- **Telegram-бот** — остатки рекламных агентств из ежедневного отчёта в чате.
- **CoinLink** — внешняя read-only Postgres (`tracker`): кредиторская задолженность
  через функции БД (совпадает с BI). Вычитается из «доступно к выводу».
- **nums888.io** — курс анонимного TON-номера (парсинг `<title>`).
