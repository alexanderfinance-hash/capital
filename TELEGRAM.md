# Остатки агентств из Telegram

Балансы рекламных агентств подтягиваются автоматически из ежедневного отчёта,
который сотрудник публикует в рабочем Telegram-чате. Сервис читает чат ботом,
парсит сообщение со списком агентств и обновляет балансы на вкладке
**«Компания» → «Рекламные агентства»**. Ручная правка суммы остаётся —
автосинк её перезапишет при следующем отчёте.

## Как это работает

- Бот состоит в чате и читает сообщения (long-polling `getUpdates`).
- Фоновый воркер каждые ~15 минут дёргает `/api/sync/telegram`.
- Эндпоинт берёт **самое свежее** сообщение-отчёт с момента прошлого синка,
  разбирает строки вида `Название — сумма`, и для каждой строки:
  - находит агентство по названию (без учёта регистра) и обновляет баланс,
    дату «обновлено» и подпись «кто внёс» (имя автора сообщения);
  - если агентства нет — создаёт новое (можно отключить
    `TELEGRAM_AGENCY_AUTOCREATE=false`).
- Позиция в ленте (`offset`) хранится в БД (`TelegramState`), поэтому одни и те
  же сообщения не обрабатываются повторно.

## Формат сообщения

Одно сообщение со списком агентств. Заголовок/дата игнорируются. Примеры строк,
которые корректно распознаются:

```
Остатки агентств 09.06
Meta Ads — 128 400$
Google Ads: 86 200
TikTok Ads 42 750$
Microsoft Ads = 18 300
X / Twitter — 9 100$
```

Поддерживаются разделители `—`, `–`, `-`, `:`, `=`, `·`, `•`, `>`, `|`, таб;
разделители тысяч (пробел, неразрывный пробел, запятая), символы валют
(`$`, `USDT`, `руб`), суффиксы `к`/`k` (тысячи) и `млн`/`m`. Строки-заголовки
(«Остатки…», «Баланс…», «Итого…», даты) отбрасываются.

Сообщение считается отчётом, если содержит слова из `TELEGRAM_REPORT_MARKER`
(по умолчанию `остат|баланс|агентств`) **или** в нём ≥2 распознаваемых строк
вида «название — сумма».

## Настройка бота

У нас есть сервисный бот **@financeanalyticsUnico1_bot**. Проверить и подключить:

1. **Токен.** Открыть @BotFather → `/mybots` → выбрать `@financeanalyticsUnico1_bot`
   → **API Token**. Если бот недоступен/утерян — создать новый: `/newbot`,
   задать имя, получить токен.
2. **Приватность.** @BotFather → `/mybots` → бот → **Bot Settings** →
   **Group Privacy** → **Turn off** (Disable). Без этого бот в группе видит
   только команды/упоминания, а не обычный текст отчёта.
   _Альтернатива:_ сделать бота администратором чата — тогда он видит всё.
3. **Добавить в чат.** Пригласить `@financeanalyticsUnico1_bot` в рабочий чат,
   где публикуются остатки.
4. **Проверить токен и узнать chat id.** На сервере (или локально):
   ```bash
   curl -s "https://api.telegram.org/bot<ТОКЕН>/getMe"
   # затем попросите сотрудника написать в чат и выполните:
   curl -s "https://api.telegram.org/bot<ТОКЕН>/getUpdates" | grep -o '"chat":{"id":[-0-9]*'
   ```
   `chat.id` группы — отрицательное число (например `-1001234567890`).
5. **Прописать секреты на сервере** в `.env` (рядом с остальными ключами,
   в репозиторий не коммитятся):
   ```
   TELEGRAM_BOT_TOKEN="123456:ABC..."
   TELEGRAM_CHAT_ID="-1001234567890"
   ```
   и перезапустить: `./deploy.sh` (или `docker compose up -d`).

> Важно: на боте **не должен** быть установлен webhook — иначе `getUpdates`
> вернёт ошибку 409. Снять: `curl "https://api.telegram.org/bot<ТОКЕН>/deleteWebhook"`.

## Переменные окружения

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен бота от @BotFather (обязательно) | — |
| `TELEGRAM_CHAT_ID` | Ограничить обработку одним чатом (рекомендуется) | все чаты |
| `TELEGRAM_REPORT_MARKER` | Regex-маркер сообщения-отчёта | `остат\|баланс\|агентств` |
| `TELEGRAM_AGENCY_AUTOCREATE` | Создавать неизвестные агентства | `true` |
| `SYNC_TELEGRAM_CRON` | Расписание воркера | `*/15 * * * *` |

## Диагностика

- Ручной workflow **Actions → Verify server config** покажет, заданы ли
  `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID`, и последние строки логов воркера
  (там видно ответ `/api/sync/telegram`).
- Ответ синка содержит `consumed` (сколько апдейтов прочитано), `updated`,
  `created`, `skipped` и `entries` — удобно для отладки парсинга.
