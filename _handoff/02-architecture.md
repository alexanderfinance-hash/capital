# 02 — Архитектура и инварианты

Подробности по продукту — в `PRD.md`. Здесь — техническая карта и те невидимые
правила («инварианты»), которые легко случайно сломать.

## Контуры приложения

Два независимых «контура»:

1. **Личный капитал** = Крипта (авто) + Авто (вручную) + Прочее (вручную) +
   Свободные деньги. Большая цифра наверху личного дашборда. Компания в неё **не**
   входит.
2. **Компания** (отдельная вкладка, 3 раскладки: дашборд / калькулятор / отчёт).
   Общий баланс = USDT-кошельки + рекламные агентства.

## Ключевые формулы (НЕ ломать без перечитывания PRD §3, §8, §9)

- **Свободные деньги** = стартовый остаток + дивиденды − расходы, *случившиеся
  ПОСЛЕ даты старта*. У стартового остатка есть дата «как на» — операции до неё
  уже «прожиты» и в расчёт не входят. Может уходить в минус — показываем как есть.
- **Доступно к выводу (компания)** = кошельки + агентства − (недельный ФОТ ×
  недель запаса) − тех. расходы − резерв на агентства − кредиторка CoinLink.
  Резервы регулируются ползунками (what-if), пересчёт мгновенный.
- **Операция вывода** = только запись в журнал + авто-дивиденд на ту же сумму в
  личном контуре. Баланс компании она напрямую НЕ уменьшает — реальный отток USDT
  отразится сам при следующем синке кошельков. (Так нет двойного счёта.)

## Источники данных и синки

Каждый синк — это `src/lib/sync/<name>.ts` + роут `src/app/api/sync/<name>/route.ts`.
Воркер (`src/worker/index.ts`) дёргает роуты по cron с заголовком `CRON_SECRET`.

| Синк | Что делает | Расписание (ENV) |
|------|-----------|------------------|
| `crypto` | Балансы кошельков из блокчейна + оценка по CMC, снапшоты | `SYNC_CRYPTO_CRON` (10 мин) |
| `expenses` | Расходы из Google Sheets (лист «Отчет»), ₽→$ по ЦБ | `SYNC_EXPENSES_CRON` (1 час) |
| `dividends` | Доходы/дивиденды из ДДС-листа Google Sheets | `SYNC_DIVIDENDS_CRON` (15 мин) |
| `telegram` | Остатки агентств из отчёта в Telegram-чате | `SYNC_TELEGRAM_CRON` (15 мин) |
| `coinlink` | Кредиторка из внешней read-only БД (функции БД) | `SYNC_COINLINK_CRON` (30 мин) |
| `tonnums` | Курс TON-номера с nums888.io | `SYNC_TONNUMS_CRON` (1 час) |

Кнопка «обновить» в личном контуре запускает синк крипты вручную.

## Правила сбора крипты (важные тонкости)

- **Компания — только USDT.** В баланс кошелька компании идёт ТОЛЬКО токен кошелька
  (USDT). Нативная монета сети (BNB/TRX/ETH для газа) и прочие токены (USDC) НЕ
  считаются — иначе балансы завышаются. USDT компании в трёх сетях: Tron (TRC20),
  BSC (BEP20), Ethereum (ERC20). У BEP20/ERC20 USDT разная разрядность (18 vs 6).
- **Личные кошельки — весь мульти-монетный портфель** (в отличие от компании).
- **Tron TRX — только свободный** (нестейканный/неделегированный). Замороженный
  ради ресурсов/голоса в баланс не идёт (PRD §9.5).
- **USDT-TRC20** читается напрямую с контракта (`balanceOf`), не из кэш-списка
  токенов аккаунта (тот бывает неполным).
- **Устойчивость:** провайдеры (`src/lib/crypto/providers.ts`) при недоступности
  источника возвращают последнее известное значение, не ноль. Время синка не
  сдвигается при неуспехе.

## Модель данных (Prisma)

Полная схема — `prisma/schema.prisma` (хорошо прокомментирована). Ключевые модели:

- `User` — единственный пользователь (пароль bcrypt).
- `Asset` — личные активы (крипто-агрегаты + ручные). `bucket` (crypto/vehicles/
  cash/other), `currency` (USD/RUB → `nativeValue` хранит исходную сумму),
  `investment` (показывать в «Других инвестициях»).
- `Wallet` — адреса для синка; `scope` (personal/company), `chain`, `token`,
  `group`/`kind` (для компании), `holdingsJson` (разбивка по монетам).
- `Agency` — остатки рекламных агентств (из Telegram / вручную), `enteredBy`,
  `updatedAt` → бейдж свежести.
- `Reserve` — синглтон ползунков what-if (ФОТ, недели, тех., резерв агентств).
- `Dividend` — дивиденды (авто из выводов + ручные).
- `ExpenseMonth` / `ExpenseCategory` / `ExpenseSubcategory` — расходы из Sheets.
- `MonthlyIncome` — доходы по месяцам из ДДС-листа.
- `OtherInvestment` — статьи расходов, реклассифицированные в инвестиции (напр.
  обучение) — вынуты из расходов, показаны отдельно, в портфель НЕ входят.
- `CapitalSnapshot` — ежедневные снимки (scope: personal/crypto/company) → графики.
- `PriceCache`, `FxRate` — кэш котировок и курса ЦБ.
- `SyncState` — последний успешный синк по источнику (для бейджей).
- `CoinlinkPayable` — синглтон кредиторки + разбивка по партнёрам.
- `TelegramState` — курсор getUpdates (offset), чтобы не обрабатывать сообщения
  повторно.

## Аутентификация

Один пароль (один пользователь). bcrypt-хеш сидится из `APP_PASSWORD`. Сессия —
подписанный JWT в httpOnly-cookie (`jose`, edge-safe). Middleware закрывает все
страницы кроме `/login` и `/api/auth/*`. Сменить пароль: поменять `APP_PASSWORD`
и выполнить `npm run db:seed` (или `npm run set-password`).
